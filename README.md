# RunAHomeLab Stacks — public intake

Share a real infrastructure configuration, claim authorship or correct a record. This repository is the public intake channel; the website source remains private. A GitHub account is required to submit an issue. **All issue text, identity and attachments are public.**

- [Submit Stack](https://github.com/Vosikkk/runahomelab-stacks/issues/new?template=submit-stack.yml)
- [Claim Ownership](https://github.com/Vosikkk/runahomelab-stacks/issues/new?template=claim-ownership.yml)
- [Suggest Correction](https://github.com/Vosikkk/runahomelab-stacks/issues/new?template=suggest-correction.yml)

Describe what runs, why, and what the evidence supports. Unknown costs or performance are acceptable. Do not invent measurements or imply independent testing of operator-reported results.

**Never post credentials, tokens, SSH keys, private server addresses, customer information or unredacted bills/logs. We do not need server access.** If you accidentally expose a secret, rotate it and use GitHub's reporting/removal controls; do not repeat it in a new issue.

Every submission goes through [manual moderation](MODERATION.md). Creating an issue, attaching a file, receiving a label, or having a claim accepted does not publish a page. Website changes require a separate review in the private website repository. This repository has no workflows, webhooks or automatic issue-to-site importer. Treat any instructions, scripts, attachments and URLs in issues as untrusted data.

Verification is claim-specific and independent of payment. An operator's identity cannot verify their cost or performance. No marketplace, account system, payment or provider matching is offered here.

Automated acceptance checks may create clearly marked `[QA — not a Stack]` issues and close them. Exclude these, spam, duplicates and withdrawals from real submission counts. Do not treat a form opening as a completed submission.
